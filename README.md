# Sobi's Multiverse - MVP Documentation Pack

This folder contains the starting documentation for the new portfolio build.

Read `VIBECODER_PROMPT.md` first when handing the project to an AI coding agent.

Core project docs:
- `plan.md` = ultimate vision, MVP scope, and roadmap
- `docs/design.md` = design language and visual rules
- `docs/architecture.md` = technical structure and data model
- `docs/rules.md` = non-negotiable agent/development rules
- `docs/memory.md` = durable cross-session context for AI agents

The MVP deliberately avoids the final universe-specific visual effects. Build the skeleton, content, and architecture first. Then make the site weird.
